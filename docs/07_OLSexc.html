07/二変量回帰分析：実習編

概要
（R実習回）二変量回帰分析について、これまで学んだことをふりかえるとともに、自分でR上で実装し、その結果を解釈してみる。

実習の準備

Posit Cloudの準備

Posit Cloudにログインし、前回のWorkspace（例えば「ICPA2」）に入ったら、以下の準備を行おう。

  • セッションのリスタート：最上部ツールバーのSession>Restart R
  • オブジェクトのクリア：右上Environmentの🧹をクリック
  • 新しいスクリプトの作成と保存：ツールバーFile直下のアイコンからR Script
    • 「07_OLSexc.R」などの名前をつけて保存

データのインポート

次に今回の実習で使うドーナツデータ（donuts.RData）をダウンロードしインポートする

  • WebClassにアクセスし「第7回R実習データ（ドーナツ）」からデータをダウンロード
  • PositCloud上にアップロードした上でdta <- readRDS("donuts.RDS")を実行しインポート1

データフレームオブジェクト

ここまで済んだら、ドーナツデータはdtaというオブジェクトに保存されていることがEnvironmentペーンを見るとわかる。復習になるがオブジェクトとは数値やデータを格納しておく箱のようなもので、後で自由自在に呼び出すことができる。今回のdtaはオブジェクトの中でもデータフレームという形で保存されている。データフレームであれば以下のようにデータ構造を把握できる。

データを見ると5つの変数が含まれていることがわかる。コードブックは以下の通り。

Rの関数と引数

ここで平均を計算するmean()関数を見てみよう。一般に関数の中に書き込むもの引数（ひきすう：argument）と呼ぶ。mean()の最初の引数には平均を計算したいベクトル形式のオブジェクトを書き込む。次のna.rm = TRUEは欠損値を無視するというオプションを指定する引数である。

なおここで今回の第一引数はdta$weightとなっている。$演算子を使うことで、データフレームの中の変数ベクトルを取り出すことができる。したがって変数をドーナツに変える場合は以下のようにする。

sum(is.finite(dta$donuts)) # 観察数：ドーナツ

mean(dta$donuts, na.rm = TRUE) # 平均：ドーナツ

散布図の作成

記述統計の次に行うべきは散布図の確認である。ドーナツを食べるほど体重は増えるのか、散布図をプロットして変数間の関係を確認できる。また、どれが外れ値なのかも確認できる。以下のコマンドと実施結果を見る限り、ドーナツを食べると体重は増えそうである。外れ値はなさそうである。

plot(dta$donuts, dta$weight)

二変量回帰分析

二変量モデルのOLS推定

独立変数\(X\)と従属変数\(Y\)を以下のようにモデル化する。

\[ Y_i=\beta_{0}+\beta_{1}X_i+\varepsilon_{i} \]

この時、\(\beta_{0}\)は切片で、\(X\)の値が0の時の\(Y\)、\(\beta_{1}\)は傾きで\(X\)の値が1単位増大した時に\(Y\)がどれくらい増えるか、\(\varepsilon\)は誤差項で、\(X\)以外に\(Y\)に影響を与える要因全てである。

傾き\(\beta_{1}\)と切片\(\beta_{0}\)をそれぞれ最小二乗法（OLS）を使って推定した値をそれぞれ\(\hat{\beta}_{0}\)と\(\hat{\beta}_{1}\)とすると、以下の通り計算される（\(\bar{X}\)と\(\bar{Y}\)はそれぞれ\(X\)と\(Y\)の平均）。

  • 傾き：\(\hat{\beta_{1}}=\frac{\sum(X_i-\bar{X})(Y_i-\bar{Y})}{\sum(X_i-\bar{X})^2}\)
  • 切片：\(\hat{\beta_{0}}=\bar{Y}-\hat{\beta_{1}}\bar{X}\)

上記のOLS推定値のばらつきを標準誤差（standard error）と呼ぶ。一定の条件を満たす場合、傾き\(\hat{\beta_{1}}\)の標準誤差は\(\text{var}(\hat{\beta_{1}})=\frac{\hat{\sigma}^2}{N\times\text{var}(X)}\)で計算できる。母集団における真の傾きを\(\beta_{1}\)とした場合、推定される\(\hat{\beta_{1}}\)は\(\beta_{1}\)を期待値、\(\sqrt{\text{var}(\hat{\beta_{1}})}\)を標準偏差とする正規分布にしたがう。

OLSの実装と解釈

OLS推定をR上で実施するにはlm()関数を使う。lm()関数に限らず、Rではコマンドのヘルプを?関数で閲覧できる。?lmと入力すると、lm()関数の使い方が載っている3。lm()関数の第一引数はformulaであり、y ~ xのように従属変数と独立変数をモデル化する。data引数では使うデータを指定する。

ここでドーナツデータを使い、ドーナツと体重の二変量モデルをOLS推定してみよう。以下のコマンドで推定を実施し、OLS_resultというオブジェクトに保存できる。

OLSresult <- lm(weight ~ donuts, data = dta)

このOLS_resultオブジェクトをもう一度コンソールに打ち込んでも良いが、これだと結果が見づらい。以下のようにsummary()を使って結果をわかりやすく表示できる。

上記で注目すべきはまずCoefficietsの欄である。

  • Estimateはそれぞれ切片(intercept)とdonutsの傾きを表している。(intercept)が55.6ということは、ドーナツを全く食べていない場合の平均体重は55.6キロ程度ということである。donutsの傾きは4.13だが、これはドーナツを週一個多く食べるごとに体重が4.13キロ増えることを意味する。
  • Std. Errorでは切片および傾きの標準誤差が表示されている。donutsの標準誤差を見ると0.87程度だが、これが傾き推定値のばらつきを表している。
  • t valueとPr(>|t|)は統計的仮説検定に関わる。詳細は次週以降。

次に決定係数\(R^2\)もわかる。下から2行目のMultiple R-squaredがそれで、この結果では0.67くらいである。体重のばらつきの67%がこのモデルで説明されていることを意味する。4

分析結果を散布図上に書き込む

以上の分析から、ドーナツと体重の関係は\(体重_{i}=55.6+4.13\timesドーナツ_{i}\)であると推定された。この式が表す直線は以下のコマンドで散布図上に描ける。

plot(dta$donuts, dta$weight)
abline(OLSresult)

一部のデータを使った分析

頑健標準誤差（時間があれば）

傾き\(\hat{\beta_{1}}\)の標準誤差は基本的に\(\text{var}(\hat{\beta_{1}})=\frac{\hat{\sigma}^2}{N\times\text{var}(X)}\)で計算できるが、誤差項の均一分散や誤差項同士の相関がない場合に限られる。不均一分散や誤差項同士の相関が生じている場合には、頑健標準誤差という別の計算式を使った標準誤差を使う。

実は頑健標準誤差はRのデフォルト機能では計算できない。ここで使うのはパッケージである。ライブラリとはRに機能を追加するもので、ゲームで言ったらMODとかに近い（多分）。今回はAERパッケージをインストールし、Rに組み込む。インストールはinstall.packages()5でできるが、これは基本一回やればよい。その上でlibrary()コマンドを実行して、Rに組み込む。library()コマンドで組み込んだパッケージはセッションを立ち上げるたびにリセットされるので、その度に実行し直すこと。

install.packages("AER") # これは一度だけで大丈夫
