08/確認小テスト

締切：2026年11月20日24:00

以下の文章を読み、続く問題に答えなさい。なお回答はWebClass上とする。

文章

政治体制は経済にどのような影響を与えるだろうか。特に民主主義体制は所得の分配を平等にするのだろうか、それとも不平等にするのだろうか。この問いを検証するために、世界167カ国の民主主義度と所得の不平等度のデータを収集した。このデータの記述統計とコードブックは以下の通り。

変数 観察数 平均 標準偏差 最小 最大 備考
dem_score14 167 5.55 2.18 1.08 9.93 エコノミスト誌による民主主義度の指数。高いスコアほどその国の民主主義スコアが高いことを意味する。
gini10 153 40.13 9.22 24.70 74.30 2000年から2010年までの所得の不平等度を表すジニ係数。高いスコアほどその国の所得が不平等であることを表す。

このデータを用いて、モデル【１】をOLSで推定してみよう。R上でこのモデルを推定するコマンドは【２】になる。OLS推定を実行したところ、\(\hat{\beta}_{1}=-0.8944\)、標準誤差は\(0.3489\)になった。

問題

  1. \(民主主義度_{i} = \beta_{0} + \beta_{1} 所得の不平等度_{i} + \varepsilon_{i}\)

問２：上の文章の【２】に当てはまるのは以下のどれか。なおデータセットはworld、分析結果はOLS_resultというオブジェクトに格納されているものとする。

  2. OLS_result <- lm(gini10 ~ dem_score14, data = world)
